# Report detail windows: size, sticky headers, red negatives, cleaner descriptions

Applies to the detail windows opened from Job Costs, Balance Sheet, Income Statement and A/P.

1. **Bigger window** so the Actions column fits without side-scrolling (one size up, still one line per row).
2. **Sticky headers**: the Type / Date / Name / Description... header row stays at the top while scrolling.
3. **Negatives in red parentheses**: e.g. -$7,200.00 shows as **($7,200.00)** in red, in Amount, Balance and Total.
4. **Descriptions (data only, no code)**: on this job's 4020 Project Manager lines, ELG Consulting descriptions like "Project Management - June 2026", "Project Management - April" and "PM - October 2026" become just "June 2026", "April 2026", "October 2026", matching the OST checks. The bill and its accounting entry both get updated; amounts untouched.
